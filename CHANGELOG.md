# Changelog

Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), versions follow
[Semantic Versioning](https://semver.org/).

## [0.3.0] – 2026-11-19

Ready for everyday use: autostart, adding files right away, selectable compute device.

### Added
- `localrag autostart --enable/--disable`: the service with the watcher starts invisibly at Windows sign-in.
- Language model in the config: `llm_url` and `llm_model` (environment variables take precedence).
- Compute device for the embedding and reranker model: `device = "cpu"` in the config or `LOCALRAG_DEVICE`,
  so the GPU stays free for a local language model.
- Source code as a format, only with `code = true`, split at functions and classes.
- Answer-quality measurement (`eval/run_answer_eval.py`) with a judge model, citation check and trap
  questions.
- Adding files right away: `localrag add`, an Explorer "Send to → LocalRAG" entry (`localrag sendto --enable`)
  and drag & drop in the web UI (inbox folder `inbox`). New API endpoints `/index` and `/upload`.

### Fixed
- An index run without new vectors left a write transaction open. In the service this blocked the watcher
  and further uploads until the timeout.

### Changed
- HTML documentation generated by tools (Sphinx, Doxygen, Javadoc …) is skipped; `steamapps` is excluded by
  default.
- Presentations show "Folie N" (slide N) instead of "Seite N" (page N).

## [0.2.0] – 2026-11-18

Everyday features: filters, config, automatic updates, web UI, more formats.

### Added
- **Filters in the query:** `type:pdf`, `in:Rechnungen`, `-in:Backup`, `after:2024-03`, `before:2024-07`.
  They work in the CLI, web UI, HTTP API and MCP. With filters, vector search computes exactly within the
  matching subset. Filters are not sent to the language model.
- **Config file** `~/.localrag/config.toml` (`LOCALRAG_CONFIG`) with `folders`, `exclude`, `max_file_mb` and
  `db`. `localrag config` shows it, `localrag config --init` creates a template.
- **Exclusion rules:** names, patterns (`*backup*`) and paths. Files excluded later disappear from the index
  on the next run.
- **Watcher:** `localrag watch` or `localrag serve --watch` keeps the index up to date. It catches up once on
  start, then collects events for 2 s. Deleted and renamed files and folders are removed from the index.
- **Web UI** at `http://127.0.0.1:8765`: search, answers with clickable citations, source cards, "open" and
  "show in folder", PDFs in the browser at the matching page. Light and dark theme, also for narrow windows.
- **Formats:** Excel (`.xlsx`/`.xlsm`, per sheet, header repeated in long tables), CSV, PowerPoint (`.pptx`,
  per slide with tables and notes), HTML (structured by headings), e-mails (`.eml`, Outlook `.msg`) with
  headers and attachments. Program files that also end in `.msg` and CSV data exports with more than 5,000
  rows are skipped instead of reported as errors. Checked against all files on C: and D:: 1,900 files in the
  new formats, one real error.
- API endpoints `/stats`, `/file/{id}` and `/open`.

### Security
- The service rejects requests with a foreign host header (protection against DNS rebinding). `/open`
  requires a custom header that foreign websites cannot send. Only indexed files are served.

### Changed
- Database connections wait up to 30 s for locks and no longer write anything on open if the schema is
  current. This keeps the service, watcher and CLI out of each other's way.

## [0.1.0] – 2026-11-17

First published version.

- Hybrid search: BM25 (SQLite FTS5, German stemming) plus bge-m3 vectors (sqlite-vec), combined with
  Reciprocal Rank Fusion. For full sentences the keyword list counts less.
- `localrag ask`: answers with citations via a local language model (LM Studio or another OpenAI-compatible
  server).
- Optional cross-encoder reranker (`--rerank`).
- `localrag serve`: background service with a loaded model and HTTP API.
- `localrag mcp`: MCP server for Claude Desktop and Claude Code, restrictable to folders with `--allow`.
- Formats: PDF (OCR for scans via Windows OCR), DOCX, Markdown, TXT (including UTF-16).
- Incremental indexing, merging of near-identical hits.
- Scales to whole drives: junctions are skipped, word and data lists left out, vectors kept in RAM.
- Eval set with measurements: keyword, vector, hybrid and reranker, plus a comparison with Windows Search.
